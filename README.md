# Noah Abdallah Portfolio — 2026

A production-ready static portfolio for GitHub Pages.

## Included
- 8 featured case studies
- 14-project selected archive
- Cedars Playing Cards standalone on-site case study with Kickstarter launch link
- Motion page linking to the existing public motion, logo-animation and VFX/3D archives
- About / positioning page
- Responsive desktop, tablet and mobile layouts
- Optimized WebP project assets
- Lightbox galleries and subtle scroll interactions

## Deploy
Back up the current `kozoo7/my-portfolio` repository, then replace the published branch contents with everything in this folder and push. GitHub Pages will serve `index.html`.

## Contact details
No email or LinkedIn URL was invented. Add your preferred contact links to the footer before launch if you want direct recruiter contact.

## Motion + AI update
When the new video links are ready, update `motion.html`. The main site structure does not need to change.

## Source files
Heavy AI/PSD/Blender/print-production source files are intentionally not copied into the live website. The site uses optimized derivatives from the uploaded archive to keep page weight practical.
